# Painlesslyf

A faith-centered blog platform for truth, grace, and the roadmap back to God's heart for life and marriage.

## Installation Guide (XAMPP)

1. Copy the `painlesslyf` folder into `xampp/htdocs/`
2. Copy `includes/config.example.php` to `includes/config.php` and set your database credentials
3. Start Apache and MySQL from XAMPP
4. Open phpMyAdmin: http://localhost/phpmyadmin
5. Import the SQL from the `sql/` folder
6. Visit: http://localhost/painlesslyf/
7. Admin panel: http://localhost/painlesslyf/admin/
