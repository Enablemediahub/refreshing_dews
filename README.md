# Refreshing Dews

A personal website for sharing daily life experiences through written blog posts and dedicated audio messages.

## Installation Guide (XAMPP)

1. Copy the `refreshing_dews` folder into `xampp/htdocs/`
2. Copy `includes/config.example.php` to `includes/config.php` and set your database credentials
3. Start Apache and MySQL from XAMPP
4. Open phpMyAdmin: http://localhost/phpmyadmin
5. Import the SQL from the `sql/` folder
6. Visit: http://localhost/refreshing_dews/
7. Admin panel: http://localhost/refreshing_dews/admin/

## Logo

Site logo: `assets/logo/refreshing-dews-logo.png`

Replace this file with your client's logo if needed, then update it in Admin → Site Settings.
